# una-pretensao-erro-figma

Lista de erros identificados:

Chave PIX inválida
Valor digitado incorretamente
Usuário não revisa os dados antes de pagar
Falha de conexão durante o pagamento

📊 Classificação dos erros
Erro	Frequência	Gravidade	Recuperação
Chave: PIX inválida -	Alta -	Baixa -	Fácil
Valor: incorreto	- Alta	- Alta -	Média
Não revisar dados:	- Alta	- Muito - alta - Difícil
Falha de conexão:	- Média	- Média	- Fácil
